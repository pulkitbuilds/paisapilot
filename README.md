# PaisaPilot – AI money copilot (Next.js 14)
SMS → ledger, scam guard, 50/30/20 budget, old-vs-new tax, SIP "leak to wealth" planner.
## Run
npm install && npm run dev
## Deploy on Vercel
1. Push this folder to GitHub. 2. vercel.com → Add New Project → import repo → Deploy (zero config).
3. Optional AI explainer: add env var NVIDIA_API_KEY (from build.nvidia.com) in Project Settings.
